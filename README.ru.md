# MyPet 🐶

Милые глянцевые питомцы-виджеты, **собачка**, **бегемотик** и **панда**, которые живут поверх ваших окон. Сделано на **Tauri 2**, **Vite** и **Vanilla TypeScript**. Собака нарисована чистым SVG и CSS (без картинок, гифок и Lottie), а в покое почти не нагружает процессор.

[English version](README.md)

## Возможности

- **Три питомца с переключением на лету**: 🐶 собачка, 🦛 бегемотик (сине-фиолетовый) и 🐼 панда. Выбираются в меню по правому клику («Сменить питомца») или в трее («Питомец»), выбор запоминается. У каждого своя кнопка-фишка, видимая только при этом питомце:
  - 🐶 **Играть**: бросается мячик, собака прыгает за ним и приносит обратно.
  - 🐾 **Копать**: собака наклоняется вперёд, быстро перебирает лапами, летит земля (2 с).
  - 🦛 **Пузыри**: бегемот надувает щёки и пускает из носа мыльные пузыри.
  - 💃 **Танцевать**: бегемот покачивается из стороны в сторону, вокруг взлетают нотки (3 с).
  - 🤸 **Кувырок**: панда приседает, подпрыгивает, делает сальто назад и встаёт на лапы (1,8 с).
  - 🥋 **Ниндзя**: панда быстро крутится, повязывает красную повязку и встаёт в боевую стойку (1,5 с; это же её трюк по двойному клику).
- **Реакция на курсор**: быстро проведите мышью у головы питомца, и он поднимет лапу, чтобы поймать курсор, а глаза будут следить за ним (`CATCHING`, около 1 с после остановки мыши). Скорость мыши считается в том же Rust-потоке, что отвечает за сквозные клики, поэтому реакция работает и над прозрачной областью вокруг питомца.
- **Гардероб**: правый клик, «🎩 Аксессуары»: 🎉 новогодний колпак, 😎 очки или 👑 корона (или без аксессуара). Аксессуар двигается вместе с головой во всех анимациях, запоминается в `settings.json`, а торчащая шляпа не ломает клики (хитбоксы пересчитываются при смене).
- **Ест буфер обмена** 📋: когда копируете новый текст, питомец открывает рот, к нему слетаются маленькие символы (A, B, 1, @…), он жуёт 1,5 с и облизывается (`EATING_TEXT`). Это только анимация: текст из буфера лишь сравнивается по хэшу, чтобы заметить смену, и нигде не сохраняется, не логируется, не отправляется и не показывается (символы летят случайные). Опрос идёт раз в секунду и всегда: **спящий питомец просыпается, чтобы съесть текст**, потом возвращается в покой (и может снова уснуть). Отключается кнопкой 📋 в меню по правому клику (`eatClipboard`).
- **Питомец-корзина** 🗑️: перетащите файл из проводника на питомца. Он откроет рот, иконка документа полетит от курсора ко рту, питомец прожуёт (`EATING_FILE`), и файл уйдёт в **Корзину Windows** (его можно восстановить). Файл, брошенный мимо питомца (на прозрачную часть окна), игнорируется. Безопасность: принимаются только обычные файлы (не папки и не ссылки), не больше 20 за раз, никогда сам exe программы и её настройки, а если питомец занят, злится или спит, ничего не происходит. Отключается кнопкой 🗑️ в меню (`eatFiles`).
- **Реакции на клики**: одиночный клик заставляет питомца подпрыгнуть, а над головой на 1 с появляется случайный символ (! ? ❤️ ♪ ✨ ⭐). **Двойной клик** запускает фирменный трюк: собака крутится на 360° и садится 🌀, бегемот делает «прыжок-бомбочку» и разбрызгивает воду 💦, панда становится ниндзя 🥋 (по 1,5 с). Медленные клики радуют питомца, 5 быстрых кликов за 2 с по-прежнему злят.
- **Вид «глянцевого 3D-эмодзи»**: SVG с градиентами, окрас меняется через CSS-переменные (`--dog-primary`, `--dog-secondary`, …) и сохраняется.
- **Эмоции** (машина состояний в `src/DogStateMachine.ts`):
  - **Радость**: плавно погладьте (зажатая левая кнопка и движение мыши), собака виляет хвостом, появляются сердечки.
  - **Злость**: 5 кликов быстрее чем за 2 секунды, собака трясётся, прижимает уши.
  - **Обида**: после злости убегает к краю экрана; 3 секунды плавного поглаживания (или «Позвать собаку» в трее) мирят с ней.
  - **Сон**: через 2 минуты бездействия закрывает глаза, появляются «Zzz». Опрос и таймеры останавливаются.
  - **Кормление**: «Покормить» роняет сверху еду питомца, он ловит и жуёт её: собаке 🦴 косточка, бегемоту 🍉 арбузная долька, панде 🎋 бамбук. У каждого питомца свой сохраняемый счётчик.
- **Сквозные клики**: прозрачные области пропускают клики на рабочий стол, мышь ловит только сама собака.
- **Перетаскивание**: удержание ~350 мс и перетаскивание, либо `Shift` + перетаскивание (настраивается). Обиженную собаку тоже можно схватить.
- **Размер**: `Ctrl` + колесо (100–600 px), ползунок в меню по правому клику или меню трея.
- **Меню по правому клику**: размер, «Покормить», «Спать», «Выход».
- **Системный трей**: Показать/Скрыть, Покормить, два трюка активного питомца, Позвать питомца, Питомец (смена), Размер, Выход.
- **Несколько мониторов**: собака прячется у настоящего края рабочего стола, а не на соседнем экране.
- **Сохранение настроек**: размер, режим перетаскивания, цвета, текущий питомец и счётчики еды хранятся в JSON.

## Управление

| Действие | Результат |
| --- | --- |
| Плавное поглаживание (ЛКМ зажата и движение) | Радость |
| Одиночный клик (без второго в течение 250 мс) | Подпрыгивание и случайный символ над головой |
| Двойной клик | Собака: оборот на 360° и сесть · Бегемот: «бомбочка» с брызгами · Панда: ниндзя-стойка |
| Быстро провести мышью у головы | Питомец поднимает лапу и пытается поймать курсор |
| Скопировать новый текст | Питомец его «съедает» (только анимация, ничего не сохраняется) |
| Бросить файл на питомца | Питомец съедает его → файл уходит в Корзину |
| 5 быстрых кликов (< 2 с) | Злость, затем обида |
| Удержание ~350 мс и перетаскивание (или `Shift` + перетаскивание) | Перенос собаки |
| `Ctrl` + колесо | Размер |
| Правый клик по питомцу | Меню (размер, Покормить, два трюка — Играть/Копать, Пузыри/Танцевать или Кувырок/Ниндзя —, Спать, Аксессуары, Сменить питомца, Выход) |
| Начать перетаскивание (удержание или `Shift`) | Прерывает любую идущую анимацию |
| `F12` | DevTools (только в режиме разработки) |

## Настройки

Файл `%APPDATA%\com.mypet.dog\settings.json` (Windows):

```json
{
  "size": 300,
  "dragMode": "hold",
  "dragHoldMs": 350,
  "colors": { "primary": "#f2b366", "secondary": "#d98a3d", "ear": "#c9772b" },
  "bonesEaten": 0,
  "melonsEaten": 0,
  "bamboosEaten": 0,
  "currentPet": "dog",
  "accessory": "none",
  "eatClipboard": true,
  "eatFiles": true
}
```

- `currentPet`: `"dog"`, `"hippo"` или `"panda"`.
- `accessory`: `"none"`, `"party"`, `"glasses"` или `"crown"`.
- `eatClipboard` / `eatFiles`: включают и выключают поедание буфера обмена и файлов (то же — кнопки 📋 и 🗑️ в меню по правому клику).
- `bonesEaten` (собака), `melonsEaten` (бегемот) и `bamboosEaten` (панда): счётчики еды, показаны внизу меню по правому клику.
- `dragMode`: `"hold"` или `"shift"`.
- `colors`: любые из `primary`, `secondary`, `ear`, `belly`, `nose`, `eye` в формате `#rgb` или `#rrggbb`. Удалите ключ, чтобы вернуть цвет по умолчанию. Цвета относятся к собаке, у бегемота своя палитра в `style.css`.

## Разработка

Что нужно:

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://rustup.rs/) (stable)
- Windows: [MSVC Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) («Разработка классических приложений на C++») и WebView2 (на Windows 11 уже есть)
- Другие системы: [требования Tauri](https://v2.tauri.app/start/prerequisites/)

```bash
npm install
npm run tauri dev
```

Первый запуск компилирует Rust-зависимости и занимает несколько минут. В режиме разработки `F12` открывает DevTools.

### Новый питомец

Все питомцы используют одну машину состояний и одни CSS-анимации, поэтому новый питомец — это SVG по контракту из `src/petParts.ts` (корень `<svg id="pet" class="pet-<имя>">` и те же id частей: `#head`, `#body`, `#eyes`, `#brows`, `#mouth`, `#tail`, `#paws` и т. д.). Дайте ему свою еду, опорные точки головы для аксессуаров (`anchors`) (см. `bone.svg.ts` / `watermelon.svg.ts`), добавьте его в `PETS` (`src/pets.ts`), расширьте `PetId` в `src/settings.ts`, а палитру и особые эффекты опишите в `style.css`.

### Исправления в 0.4.1

- **Меню по правому клику у края экрана**: меню временно увеличивает окно (до 380 px). Если питомец у правого или нижнего края, окно сдвигается внутрь рабочей области монитора (питомец на экране остаётся на месте, меню открывается влево или вверх) и возвращается на место при закрытии меню.
- **Питомец терял «поверх всех окон»**: когда открывалось другое (тяжёлое / тоже topmost) приложение, например браузер, питомец мог оказаться под ним, пока по нему не кликнешь. На Windows окно теперь поднимается через `SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)` раз в 1,5 с (без кражи фокуса) и сразу при потере фокуса.
- **Поедание буфера во сне**: опрос буфера обмена больше не ставится на паузу, когда питомец спит; скопированный текст его будит.
- **Побег обиженного питомца**: математика теперь считается по размеру самого питомца (а не окна), выбирается внешний край *текущего* монитора (не та сторона, что граничит с другим монитором), на виду всегда остаётся не меньше 40% питомца, а по вертикали он остаётся в пределах монитора.
